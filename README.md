# Online Movie Ticket Booking System

An online movie ticket booking system developed as part of a group software development project. The project focuses on designing and managing a web-based platform that allows users to browse movies, view available showtimes, select seats, and book movie tickets online.

## Project Structure

```text
├── planning/            Product backlog, sprint planning & project management
├── requirements/        Functional & non-functional requirements
├── design/              UI designs, wireframes & system design
└── testing/             Test plans, test cases & testing results
```

### `/planning`

Contains project planning and management documents, including the product backlog, sprint planning, task assignments, and other project management artifacts.

### `/requirements`

Contains the system requirements documentation, including functional requirements, non-functional requirements, user requirements, and other requirements-related information for the online movie ticket booking system.

### `/design`

Contains the design artifacts for the system, including user interface designs, wireframes, system diagrams, and other documents used to demonstrate the structure and appearance of the application.

### `/testing`

Contains testing documentation, including test plans, test cases, expected results, actual results, and testing outcomes. The testing process is used to identify defects and verify that the system meets its specified requirements.

## Project Objective

The main objective of this project is to design and develop a convenient online movie ticket booking system that simplifies the process of searching for movies, selecting showtimes and seats, and booking tickets. The project also demonstrates the use of software engineering practices throughout the planning, requirements, design, development, and testing stages.

## Project Management

The project follows an organized software development process where tasks are planned and distributed among team members. Project artifacts are maintained in this repository to document the progress of the project and support collaboration among team members.

## Testing

Testing is an important part of the project and is conducted to ensure that the system functions according to its requirements. Test cases are prepared to verify different features and identify any issues that may affect the usability and functionality of the system.

For detailed testing information, test cases, and results or lots of things, see the documentation in the `/testing` directory.
